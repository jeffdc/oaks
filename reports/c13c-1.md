## How it was built

### Design notes

<.modal> is server-driven: a page renders it :if its state is set, with show and on_cancel={JS.push(...)}; the modal draws its own close control (cancel label) so no page can add a second one. Consequences go in a :note slot (Archivo) so pages need no dialog CSS. The panel is a flex column capped at the window, so long bodies scroll and actions stay in view. Edit menu items push the trigger onto the focus stack, so closing a dialog returns focus there. The quiet menu is a variant of <.edit_menu>, not a new component; its trigger is a block flex box so a row is the same height logged in and out. Rejected: per-page danger classes, hover-revealed buttons, and a separate picker component. app.css drops 263 lines and five daisyUI allowances.
