## How it was built

### Design notes

Both index lists are CSS multi-columns; they had different column-width values (220px, 260px), so between about 760px and 1000px the sub-groups took 3 columns and the species 2. They now share one rule with column-width 260px. The species card was a wrapping flex row; it is now a block with nowrap and text-overflow: ellipsis, with padding and line-height set so its row is the same 43.5px as a sub-group row. I rejected letting rows grow and aligning them by grid because the columns read down, not across.
