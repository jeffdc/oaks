## What was built

### Summary

Every title row now puts its meta (kind word, counts, stamps) on the title's line, wrapping under only when there's no room, so desktop pages use their width. Editor actions became one small Edit menu (<.edit_menu>) at the right of the row; logged out there is no menu and no space kept. Species, taxonomy, source, article, the species, sources and articles lists and search all use it, and the taxon page's extra Edit and Add Content buttons are gone. This replaces 626c's meta-under-title rule.

### UI tour

1. Open localhost:4460/species/shumardii logged out: Species and the IUCN LC stamp sit on the name's line, nothing at the right.
2. Log in and reload: a small Edit button with a chevron at the right; click it for Edit species, Make synonym of… and Delete species. Choose Delete species, then Cancel.
3. Open /taxonomy/Quercus/Lobatae: Section and 217 species beside the name; the Edit menu holds Create taxon, Edit section and Delete section; no Add Content button below.
4. Open /species, /sources, /articles and /search?q=alba: counts or subtitle beside or under the title, and New species, Create source, New article or Add species inside the Edit menu.
5. Narrow the window to phone width: the meta wraps under the title and the Edit menu stays at the top right.
6. Open /dev/components#title-row: the editor and visitor rows, wide and narrow.

## How it was built

### Design notes

The header wraps the h1 and the meta in one flex line (.oc-title-line, wrap, baseline), so the meta follows the title and drops under it only when both don't fit. The text column is flex 1 1 0, so the actions slot never wraps; it now holds only <.edit_menu>, a details[data-menu] disclosure like the masthead's Editor menu (compact button summary, list on the right edge), reusing app.js's Esc and outside-click closing plus a new close-on-choose. Items are slot entries with navigate, href or click and values, so pages pass data, not markup. Rejected: keeping the old 20rem wrap (the list would open off-screen when the menu dropped to the left) and a container query (fragile threshold). No app.css changed, so the budget stays. Section-level editor buttons are left for idea f0e0.
