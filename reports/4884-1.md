## What was built

### Summary

Agents stop their dev servers without asking Jeff: AGENTS.md tells every agent to start dev servers as background tasks and stop them with the stop-task tool (no shell kill, so no approval), and scripts/stop-dev-server <port> is the single pre-approved fallback for a server left running. It stops only a BEAM (Phoenix) process listening on that port and refuses 4444 and 4460, Jeff's servers. Jeff's local .claude/settings.local.json allows exactly Bash(scripts/stop-dev-server:*).

## How it was built

### Design notes

Two layers. The primary fix is behavioural and needs no new permission: Claude Code's background-task option plus its stop-task tool stop a server without any shell command, so nothing prompts; AGENTS.md carries the rule so every agent, not only ones briefed by this supervisor, follows it. The fallback is deliberately narrow so a blanket kill permission is never needed: the script takes only a numeric port, refuses Jeff's two server ports, finds listeners with lsof and stops a process only when it is a BEAM, leaving anything else alone with an error. The permission rule lives in Jeff's untracked settings.local.json, not the tracked project settings, since it's his machine's policy. Tested: refusal on 4460, nothing on an empty port, a bad argument, a Python listener left running with an error, and a BEAM listener stopped. Rejected: allowing kill or pkill patterns (too broad to pre-approve) and a PreToolUse hook rewriting kill commands (more machinery than the problem needs).
