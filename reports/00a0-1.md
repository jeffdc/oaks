## How it was built

### Design notes

The binary moved from _build/tailwind-linux-x64-musl-<version> to /usr/local/bin/tailwindcss-<version>, named once in the ENV line and reused as ${MIX_TAILWIND_PATH} by ADD, sha256sum and chmod, so check-toolchain only needs to read that one line (a mismatch was checked against a copy with 4.1.11). config :tailwind already reads MIX_TAILWIND_PATH; only its comment changed. A mini amd64 image with the same ENV/ADD/RUN lines built and ran the binary under Colima; the full image build was not run.
