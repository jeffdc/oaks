Jeff, 2026-11-22: a dev server for a branch that lives in another worktree (e.g. the integration branch 6b12-site-shell on :4460), started once in a tmux pane with no background time limit. make dev with no BRANCH is unchanged. With BRANCH it runs in the worktree that has the branch checked out, creating one under .claude/worktrees/<branch> if none, copies the dev database in with sqlite3 .backup when missing, migrates, and serves on PORT (default 4444).
