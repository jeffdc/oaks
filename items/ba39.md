Fly.io log aggregation is wasted on raw text formatting. Switch prod logging to structured JSON.

- Add the :logger_json dep to mix.exs.
- Configure it in config/runtime.exs, under the prod branch only; dev stays human-readable.
- Include request_id and the other standard metadata.

Crib from gallformers: config/runtime.exs (the `if config_env() == :prod` block, ~lines 68-71) and its mix.exs deps. There it is `config :logger, :default_handler, formatter: LoggerJSON.Formatters.Basic.new(metadata: :all)`, and it must live in runtime.exs, not prod.exs, because LoggerJSON has to be compiled before its formatter function can be called.
