Investigate the USDA Oak Field Guide as a potential data source for the database:

- Locate it online (likely plants.usda.gov or fs.usda.gov).
- Assess the data: species coverage, morphological data, range info.
- Determine whether it complements or duplicates Oaks of the World.
- Evaluate scraping feasibility: static HTML vs dynamic content, rate limits.
- Design a scraper architecture if viable.

The repo already has scrapers/usda_symbols.py (USDA PLANTS symbols), which currently points at the deleted CLI database (see capture 5654).
