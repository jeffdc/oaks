The tailwind hex dep (the installer, not the Tailwind binary) is locked at 0.4.1 with the constraint `~> 0.3` in mix.exs. The 0.4 to 0.5 upgrade was deferred in the 2026-11-02 dependency pass, whose aim was to set real constraints and upgrade deliberately. The `~> 0.3` constraint already allows 0.5, so it should be tightened as part of the upgrade.

The Tailwind binary version is pinned separately (config :tailwind, version: in config/config.exs, and tailwindVersion in flake.nix); scripts/check-toolchain checks they match.
