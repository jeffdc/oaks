Compare several species side by side to help with field identification: key distinguishing features (leaf shape, acorn characteristics, bark, etc.) across the selected species. Useful when an ID is narrowed to 2-3 candidates and you need to tell them apart.

User feedback (BUGS.md, a local gitignored note): they like swapping between sources on a species page and the existing compare feature (which compares sources for one species), and asked for comparing similar species, "like the table on the compare tab, but between species". They pointed at bplant's side-by-side layout (https://bplant.org/compare/187-188), noting those are custom pages for each comparison, which is probably very time consuming, so a generated comparison fits better.
