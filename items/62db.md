Public API GET endpoints are uncached. A ~60-line plug gives free bandwidth savings on read traffic.

- New OaksWeb.Plugs.ApiCache.
- Compute MD5(body) as the ETag and set it on the response.
- Honor If-None-Match: answer 304 Not Modified when it matches.
- Skip when status >= 400.
- Add it to the :api pipeline (or per-route).

Done when a repeat GET with the returned ETag gets a 304 (test it, and check by hand with curl -I).

Crib from gallformers: lib/gallformers_web/plugs/api_cache.ex.
